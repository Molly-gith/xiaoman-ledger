## 当前设计边界

- 当前账本保存在浏览器，尚无正式用户登录；本机身份标识仅用于本地命名空间，不能充当服务器认证。不会把本机记忆声称为多账号安全或云端同步。
- 大模型理解自然语言、生成受限制的查询计划；查询与金额计算在本机执行，不将全部逐笔账目交给模型。没有数据就说明，没有支持的能力不假装完成。
- 财务事实、对话记忆和分类偏好分开保存。记忆/偏好可以清除，不能连带删除账目。真正的账号接入后由服务器从登录状态确定用户，不能相信客户端传来的用户编号。
- 本轮不代用户充值、购买服务，不使用真实账目测试。新增工作流先模拟测试，真实验证使用小量虚拟样例。

## 用户如何掌控

每阶段提供实际体验链接、三至五个可直接试的问题、已验证与尚未支持的范围。用一条真实流程演示：说话 → 理解需求 → 查询当前授权账本 → 程序计算 → 展示依据 → 如需写入则由用户确认。Dify 节点使用中文名称与说明，并提供可回看的流程指南。
