## 当前设计边界

- 无需登录的本机模式保持不变；账号模式由 Supabase 验证登录与数据所有权，云端数据不回落到游客区。本机身份标识不能充当服务器认证。个人试用注册限项目组织已授权邮箱；公开注册须先确定邮件服务并验证确认邮件闭环。
- 大模型理解自然语言、生成受限制的查询计划；查询与金额计算在本机执行，不将全部逐笔账目交给模型。没有数据就说明，没有支持的能力不假装完成。
- 财务事实、对话记忆和分类偏好分开保存。记忆/偏好可以清除，不能连带删除账目。真正的账号接入后由服务器从登录状态确定用户，不能相信客户端传来的用户编号。
- 本轮不代用户充值、购买服务，不使用真实账目测试。新增工作流先模拟测试，真实验证使用小量虚拟样例。

用户追加的薪资预算与界面简化已完成本地验收，**正在发布，待线上核验**。薪资预算在「记账」页按需开启，默认关闭、自然月统计；发薪日选填，配置后可选择预算工资周期，并在账单按工资日周期查看。预计薪资只作计划基数，不记虚拟收入；三项比例合计不超过100%，余下未分配。消费/浪费达到80%轻提醒、超过100%超限，页面状态和保存跨档提示不等于系统推送。投资仅按投资性质支出计入，当期调整下期恢复，三本及账号分别保存。详见[薪资预算指南](SALARY_BUDGET_GUIDE.md)。

## 用户如何掌控

每阶段提供实际体验链接、三至五个可直接试的问题、已验证与尚未支持的范围。用一条真实流程演示：说话 → 理解需求 → 查询当前授权账本 → 程序计算 → 展示依据 → 如需写入则由用户确认。Dify 节点使用中文名称与说明，并提供可回看的流程指南。
