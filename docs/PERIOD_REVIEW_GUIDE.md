# 小满日期复盘使用指南

更新：2026-10-26。**已发布到[原PR24体验页](https://molly-gith.github.io/xiaoman-ledger/previews/pr-24/#/)。** 页面已通过虚拟账本核验；如果一直开着旧标签页，请刷新一次。

复盘帮助你看清一段时间的已记录收支、钱花在哪些分类，以及与前一段时间的差别。它不要求先填写预算或设置发薪周期。

## 使用路径

**账单选起止日期 → 复盘 → 看依据。**

1. 先确认当前是个人、家庭还是旅行账本，再到「账单」按月选择，或填自定义开始、结束日期。
2. 点击「复盘这段时间」。先核对账本名称、本段日期和前段日期，再看收入、支出、收支差额与支出分布。
3. 点击「查看本段全部账目」「查看这类支出」，或比较表中的本段、前段金额，核对对应的真实记录。展开「按分类看支出」「按性质看支出」也可查看各项依据。
4. 依据只读展示，较多记录会分页。发现日期、金额或分类有误时，回到账单编辑原记录，再重新查看复盘。

点击“查看依据”后会直接定位到账目；收起后回到原按钮。完整回归、线上核验和三尺寸界面复核已完成。

## 比较的是哪段时间

开始和结束当天都计入。本轮统一比较**紧接本段之前、天数相同的一段日期**，不自动换成上一个自然月。

例如选择2026年10月1日至7日，共7天，前段为9月24日至30日。若选择10月1日至31日，共31天，前段为8月31日至9月30日，也有31天。这些只是日期口径示例，不是用户真实账目。

变化是“本段已记录金额减去前段已记录金额”。金额以分为单位累计，再显示为元，避免小数累加误差。若所选结束日期晚于今天，页面会提示**时段尚未结束，只能比较已记录账目，不能当作完整时段的变化**。

## 数字和缺失数据怎么理解

- 收入、支出和收支差额来自本账本的交易记录；差额是收入减支出，不能当作账户余额或还能花的钱。
- 消费、浪费、投资是已有支出的性质标签。投资性质支出不是投资收益；投资账户的市值和资金转入转出不混入这份收支复盘。
- 没有记录不代表实际收入或支出为零。本段或前段任一没有记录时，不生成增减趋势。
- 若有旧账日期待核对，可先看到按本机日期归属的记录和金额；比较结论暂不可用，核对日期后再复盘。前段日期超出支持范围时也明确说明，不编造数据。
- 未填写预算、投资目标等选填内容，不会挡住复盘，也不会用0替代“未设置”。这版不判断是否超预算、不推算投资回报。

个人、家庭、旅行账本分别复盘。登录账号时仍按当前账号权限读取；本机模式仍使用本机记录。打开复盘本身不新增、删除或修改账目。

## 也可以直接说“复盘”

本轮已接入“帮我复盘这个月”“复盘这段时间”“复盘上个月家庭账本”等明确表达，与账单面板使用同一份程序计算和依据。

追问“再复盘一下”时，可以沿用上次的日期和账本；如果上次只查餐饮、消费性质或做了前月比较，新的一次完整复盘会清除这些旧过滤条件。“复盘这段时间”使用当前选定日期。你若明确说“复盘这个月餐饮支出”，则继续按餐饮查询，不擅自扩大为整本复盘。需要澄清的日期或多个账本请求会先说明。

复盘的确定文字会随对话保存；它不会生成记账草稿或写入账目。聊天入口沿用查询协议的**最长3660天**限制，超过时会引导到「账单」选择日期并打开复盘。账单面板在系统支持的日期范围内不套用这个十年左右的聊天限制。

本轮复盘不需要修改Dify工作流或追加模型调用，Dify #6与后端保持不变。复盘的金额、日期比较、依据和文字由程序生成。[与Dify的分工](dify/assistant-v2-workflow-guide.md)

## 怎么判断结果可靠

看三件事即可：日期和账本是否选对；金额能否在对应明细中核对；没有记录、时段未结束或日期未确认时，是否明确提示限制。完整回归与发布证据记录在[本轮验收](evidence/period-review-milestone-20261026.md)。

账号个人试用的实际邮件收件和确认仍未核验，公开注册的SMTP方案仍待决定；本轮复盘不把这些事项改记为已完成，也不要求重新登录后台。
