# 小满 Web Beta V0.3 V6｜UX Spec

## Onboarding
第一问：你习惯怎么管理一个财务周期？
- 按自然月（推荐）
- 按发薪日
- 自定义周期

第二问：这个周期你准备安排多少钱？
- 字段：本周期可用资金
- 资金来源拆分为可选项，不阻塞继续

## 按发薪日
只有选择后显示：通常几号发工资？

## 自定义周期
显示：开始日期 / 结束日期。

## 资金来源
入口：+ 添加资金来源（可选）
支持：工资、奖金/提成、副业/自由职业、经营收入、家庭支持/转入、存款划入、其他。
显示来源合计，并允许一键把来源合计填入“本周期可用资金”。

## 财务结构
消费约70% / 投资目标≥25% / 浪费建议≤5%；强调“方向，不是三个必须花完的钱包”。

## 记账
保持最短路径：金额 → 分类 → 消费性质 → 保存。
收入账只记录流水，不自动改变周期可用资金。

## 视觉
继续 Calm Conversational Finance；移动端优先；复杂规则渐进披露。
