# 小满 Web Beta V0.3 V6｜Product Change Spec

## 目标
从“工资驱动型记账”升级为“周期驱动型个人财务助手”。

## 已确认规则
- Financial Cycle：自然月（默认推荐）/ 按发薪日 / 自定义周期。
- 核心金额：本周期可用资金。
- Funding Sources 可选：工资、奖金/提成、副业/自由职业、经营收入、家庭支持/转入、存款划入、其他。
- 用户可以只填本周期可用资金，不拆资金来源。
- 只有选择“按发薪日”后才出现发薪日相关字段。
- 新收入记录不得自动重复增加本周期可用资金；必须显式确认。
- 消费约70% / 投资目标≥25% / 浪费建议≤5% 是结构目标，不是三个钱包。
- 删除必要支出预留与每笔“日常花销/已留好的钱”选择。
- 记账主路径：金额 → 分类 → 消/浪/投 → 保存。
- local-first 与旧备份兼容不变。

## AI 边界
AI 可解释、分类、复盘和提出建议；不可擅自修改可用资金、预算、财务阶段或投资决策。

## Gate
无固定工资、稳定工资、自由职业用户都能完成 onboarding；旧账不丢；确定性规则 100% 回归通过。
