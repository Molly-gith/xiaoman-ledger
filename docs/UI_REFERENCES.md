# 小满 UI 参考链接

核对日期：2026-09-18。后续设计讨论以真实产品链接、明确借鉴点和运行中的 Preview 为依据，不再制作独立 UI 作品集。

## 当前主 Benchmark：Cleo

Molly 已明确偏好 Cleo 的产品表达与界面：简洁、直白、以“和一个懂钱的 AI 说话”为第一心智。后续小满在不改变已确认财务规则的前提下，优先用 Cleo 检查信息层级与对话体验。

小满吸收的原则：

1. **先对话，后数据**：首页先让用户能直接说话，再按需展开财务数字和看板。
2. **先结论，后解释**：先说“你现在怎么样”，再给为什么、数据依据和详情入口。
3. **先行动，后报表**：优先给下一步动作，不把完整报表堆在第一屏。
4. **复杂能力藏在后台**：Provider、规则、评测、账户模型不要求用户理解；前台只呈现可理解的结果。
5. **人格温和但不评判**：保留 Cleo 的人格化与自然语言优势，但不复制毒舌、Roast、贷款推广或刺激消费表达。
6. **一个主入口**：小满是 AI 助手本体，记账、财务看板、账户资产、周期复盘都是对话旁的能力入口，而不是彼此平级的多个主产品。

| --- | --- | --- | --- |

## 当前已落地的界面约束

- 移除底部 tabbar。
- 首页保留记一笔 / 财务看板 / 账户与资产 / 周期复盘四个能力入口，但不与“小满”并列成主导航。
- 对话 composer 固定在底部，并处理安全区、手机键盘和底部内容留白。
- Web 与 Mobile 共用同一信息架构和视觉语言，移动端只做响应式重排。
- 真实 AI Provider 未接通时明确降级，不伪造在线 AI 能力。

后续每次 UI 迭代优先问三个问题：**Cleo 会不会把这件事讲得更简单？用户第一眼能否知道现在发生了什么？用户是否立刻知道下一步能做什么？**
