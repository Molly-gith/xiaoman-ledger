# 小满 UI 参考链接

核对日期：2026-09-18。后续设计讨论以真实产品链接、明确借鉴点和运行中的 Preview 为依据，不再制作独立 UI 作品集。

| 产品 | 官方链接 | 小满借鉴什么 | 边界 |
| --- | --- | --- | --- |
| MonAi | https://www.get-monai.app/ | 官网展示的轻量自然语言输入、聚焦记录的简洁界面；小满减少装饰与说明文字，让输入和下一步操作更直接 | 小满当前没有自动导入或已接通的 AI 对话，不以参考产品的能力冒充实现 |
| Cleo | https://web.meetcleo.com/ | 用日常语言围绕自己的钱展开对话；小满将输入持续放在聊天首页底部 | 不采用嘲讽口吻、贷款推广和刺激消费的表达 |
| Copilot Money | https://www.copilot.money/ | 官网产品图展示的数据层级，以及 Web / iPhone / Mac / iPad 的产品一致性；小满共享财务事实、组件、标签和内容顺序 | 借鉴信息呈现，不复制它的 tabbar；本轮保留 70/5/25 与现有资产口径 |

以上是针对小满的设计取舍，并非声称三个产品都采用无底栏布局。MonAi 最接近“极简 AI 记账”的输入方向；Cleo 和 Copilot 分别补充对话与财务展示参考。

本轮落地：无底栏，首页四能力入口，顶部设置/备份，普通文档流中的返回按钮，固定底部输入区，安全区与手机可视区域适配。没有新增工具、外部账号依赖或展示作品集。
