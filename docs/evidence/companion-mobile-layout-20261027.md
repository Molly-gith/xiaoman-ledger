# 对话首屏与手机适配（2026-10-27）

用户反馈：快捷入口到输入框之间存在巨大空白，手机界面不够简洁。根因是chat-thread固定height按视口比例占位，空对话仍保留完整聊天高度。

## 修改

- 空态自然高度，短消息随内容增长，长历史只设max-height并可内滚动。
- 欢迎语、快捷入口和输入框组成紧凑的首屏；独立设置入口、统一图标和44px操作区。
- 深绿用户消息和浅绿助手消息拉开层级；保留奶油色、森林绿与原有功能。
- 没有账目时移除重复的最近账目空态；主导航账单入口保留。
- 没有更改AI/Dify、模型、账户或数据规则，无真实模型调用。

## 参考与取舍

参考[Cleo](https://web.meetcleo.com/)以自然对话承接财务问题的方式，[钱迹主界面指南](https://docs.qianjiapp.com/home/index.html)强调直接记账与有内容才呈现相关信息的做法，以及[Copilot Money](https://www.copilot.money/)的交易信息层级。借鉴入口和信息组织，不复制品牌或引入借贷、营销模块。
