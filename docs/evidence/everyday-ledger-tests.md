# 日常记账浏览器验收

2026-10-24 在独立 Chrome 测试上下文完成 34 项浏览器回归，全部通过。AI 返回值和语音识别事件均为合成模拟；没有调用真实模型，没有读取或修改用户浏览器的账本。此结果验证网页交互与存储行为，不代表真实模型识别准确率或真实麦克风兼容性验收。

## 已验证范围

- 新账无需配置周期或预算；按日期保存收入和支出，历史周期、预算及旧账保留。旧账未分类金额仍计入统计，旧时间戳明确提示日期待核对。
- 本月、历史月份、跨年自定义日期均含首尾日期；汇总和明细使用同一范围，收入筛选不改变完整收支汇总。无效范围隐藏统计；月份上下边界受保护。
- AI 只生成待保存草稿。可取消、改金额、日期、收支类型和备注；一次确认原子保存多笔，双击不重复，撤销只删除本批次。后续写入会取消旧撤销入口。
- 澄清保留原始输入；请求仅传输入和日期范围汇总，不传逐笔备注或账户名称。限流、无效响应及取消请求保留输入；取消后的迟到响应不显示、不重发。
- 语音保留超过 100 字的识别文本，等待最终结束后填入，仍需用户发送和确认。未授权、不支持、临时结果、空结果、超时、取消、离开首页和迟到回调均不会覆盖原输入或自动记账。
- 390×844、1440×1000、320×760、844×390 四种尺寸无横向溢出；收入表单可滚动、保存按钮可点击，模拟键盘将可视高度缩到 410px 后仍无遮挡。对话框焦点保持在内部。
- 手动增改删、资产投入与取出、市值更新、备份恢复、清空、离线重载、旧离线页面更新、跨页面版本冲突、存储失败保留输入均通过。

## 复现

在项目根目录运行以下 PowerShell 命令。模拟地址仅用于测试构建，发布前必须使用正式配置重新构建。

```powershell
$env:VITE_AI_API_URL = 'https://xiaoman-ai-test.example/api/ai/assistant'
npm run build:github
$env:AI_BROWSER_TEST = '1'
$env:PLAYWRIGHT_CHANNEL = 'chrome'
npx playwright test --reporter=line
```

测试位于 `tests/browser/`。最终整套结果为 `34 passed (36.5s)`；浏览器测试目录 ESLint 与 `git diff --check` 通过。未启用 `AI_BROWSER_TEST` 时，8 项 AI 测试及 1 项语音转 AI 保存测试跳过，其余测试仍执行。

首页四种尺寸与资产截图由测试保存到 `test-results/everyday-*.png`。为补齐手机收入弹窗、模拟键盘和统计截图，仅定向执行对应 2 项测试，结果 `2 passed (4.3s)`，没有重复整套回归。

本轮回归发现并验证修复了取消按钮复用为发送按钮时触发意外重新提交的问题；草稿编辑测试改为按可访问控件名称定位收支类型选择框。
