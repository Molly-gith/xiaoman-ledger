# 小满薪资预算使用指南

更新：2026-10-27。入口为「记账 → 薪资预算 · 选填」。不开启也能照常记账。功能状态和证据见[金额与自动工资验收](evidence/recurring-salary-20261027.md)。

## 直接填写金额

未填写到手工资时，消费、浪费、投资的金额均为 0。首次填写 7,000 元工资，会显示：

| 项目标签 | 金额输入框 |
| --- | ---: |
| 消费（70%） | 4,900 |
| 浪费（5%） | 350 |
| 投资（25%） | 1,750 |

直接修改金额即可，括号比例跟着显示。金额精确到分，不会由显示比例反算；本次手改金额会保留，其余随工资变化。已有设置按保存的金额或比例读回，不重置为初始建议。

三项金额合计不得超过到手工资，可以留一部分未分配；浪费可填 0。它是容忍上限，不是要花完的目标。

## 发薪周期与自动工资

在「发薪与周期选项」设置发薪日。账单随即可以选择「发薪周期」；预算也可勾选「按发薪周期计算预算」，从本次发薪日到下次发薪日前一天计算，短月没有该日时取月末。

需要每月自动记工资时，**只需一次勾选「发薪日自动记工资」并保存**。自动收入使用到手工资金额，按北京时间判断日期；启用前已过去的发薪日不追记。首次启用当天恰逢发薪日，会记入当天；今后每个月最多一次。已手动记录的同月明确工资收入会跳过，不再添加第二笔。

**账号账本：后台每小时检查一次，关闭网页也可自动记工资；本机账本：网页打开、回到页面或跨日时检查，关闭后在下次打开补记。**两种方式都只处理主动开启本功能的账本。后台正常执行可能晚于零点，不能作为银行实际到账证明。

记录会标注自动来源，不代表系统已经验证银行到账。工资金额变化可以编辑该笔记录；删除后不会重新生成。调整每月工资只影响之后的发薪日，已记入的工资不改写。可随时关闭自动记工资；重新开启不补记停用期间的月份。

预算随日期自动换期，不需要每月重新设置。「仅调整本期薪资」只改变本期预算，下期恢复，**不会新增收入或修改自动工资金额**。未开启自动工资时，仅设置预算也不会产生收入。

## 提醒与账本

消费、浪费达到额度 80% 时轻提醒，超过额度显示超出金额，不会阻止记账。金额或日期待核对时不作确定超限判断。投资仅统计性质为投资的支出，不重复叠加资产划转、市值或收益。

个人、家庭和旅行账本各自保存设置与收入；切换账本会切换对应数据。停用预算保留账目和设置，也暂停自动工资。查账日期筛选不会修改历史账目。

旧备份仍可导入；新设置包含精确金额与自动工资进度，旧标签页需刷新到当前版本后使用。公开注册的邮件方案仍是独立待决事项，不影响本机使用。
