# 小满薪资预算使用指南

更新：2026-10-27。本文说明当前操作方式；测试与发布状态见[本轮证据](evidence/salary-budget-ui-20261026.md)。

薪资预算是一份可选的花费计划。不开启、不填薪资，也能直接记账；默认按自然月查看账目。

## 从哪里开启

在「记账」页展开 **薪资预算 · 选填**，填写每月到手工资，首次预填消费 70%、浪费 5%、投资 25%，立即显示各项预估金额。三项比例均可手动修改，修改工资只会重算金额，不会重置比例；已保存的预算也保留原配置。点「保存并启用」才生效。

三项比例合计可以小于或等于 100%，剩余部分显示为“未分配”，不必凑满。浪费比例可以为 0；它是你设定的容忍上限，不是要花完的目标。计算按分处理，分币尾差在已分配金额内处理，不会多分资金。

这里的薪资只是预算基数，**不会自动生成收入账目，也不代表钱已经到账或账户里还剩多少**。实际收到工资时仍按普通收入记账。

## 自然月和发薪周期

预算默认按每月 1 日至月底计算。「周期选项」中的发薪日可以留空；设置每月 1–31 日后，可以主动勾选“按发薪周期计算预算”。

工资周期从本次发薪日至下次发薪日前一天。短月没有对应日期时按月末计算。例如发薪日设为 31 日，2026 年 2 月的周期为 2 月 28 日至 3 月 30 日。

薪资预算启用并保存发薪日后，「账单」还可以选择 **发薪周期**，查看上一期、下一期或回到本期。账单仍默认按月，也可以自选起止日期；改变查看范围不会改动预算设置或历史账目。预算可以保持自然月，同时用发薪周期查账。

按发薪周期计算预算时，点击「查看本期账目」会直接打开账单的「发薪周期」。

## 提醒怎样理解

- 消费、浪费达到额度的 **80%** 时轻提醒；**超过 100%** 时显示超出金额。恰好用满不算超限，额度为 0 而发生支出时算超限。
- 投资项显示计划与已记录支出，不按消费上限告警。
- 预算面板持续显示当前状态；保存使状态跨入提醒档位时，出现一次页面提示。已经处于同一档位时，不因每笔保存重复提示。
- 提醒不会阻止记账，也不是手机系统通知；关闭网页后不会靠这项功能主动推送。
- 日期待核对或性质未设置的支出单列，暂不计入确定的已用金额，并暂停接近/超出判断。核对后会重新计算。

统计按本期账目的日期和性质计算，也包括从未设置过周期时记录的账目。**投资只统计性质为“投资”的支出**，不叠加投资账户划入划出、市值或收益；这些仍在「我的资产」中单独查看。

## 这期薪资不同，或者想暂停

在预算面板选择「仅调整本期薪资」，会按原比例重算当前显示日期内的额度。下期自动恢复预计薪资；也可以点「恢复预计薪资」提前取消临时调整。更换预算周期时会清除原周期的临时调整。两种修改都不会创建工资流水。

「调整薪资与比例」中可以停用预算。停用保留设置和全部账目，之后仍能重新开启；未开启预算时不产生预算提醒。

个人、家庭、旅行账本分别保存自己的设置。登录后的云端设置属于当前账号；本机模式使用本机账本。切换账本不会复制另一份薪资或支出。完整账本 JSON 备份包含三本的薪资预算。

## 页面更简单了

「我的」把更多设置和隐私说明收起，需要时再展开；原有预算计划仍保留。复盘先展示重点，再展开“查看收支”“与上一段比较”“花在哪里”和计算说明。薪资预算的提醒与复盘的已记录收支比较各自保持原来的计算口径。

验收时先看三个地方：是否选对账本与日期；额度是否等于自己设定的薪资分配；已用金额是否能在「查看本期账目」中核对。

账号授权邮箱的实际收件、确认返回仍待验证；公开注册的邮件服务方案尚未决定。本轮预算不要求你先解决这些问题，也不把它们标记为已完成。
