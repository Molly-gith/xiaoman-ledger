# CR-002｜投资账户与市值模型

## 目标

把“已有投资资产”与“本周期未来/实际投入”拆成两个清晰概念：资产页回答“我现在拥有什么”，周期页回答“这个周期的钱准备怎么分”。

## 已确认产品规则

- ETF / 基金等作为投资账户管理。
- 第一版只要求用户手动更新当前市值；不要求每日维护。
- 市值涨跌属于未实现资产变化，不计工资收入，也不生成普通收支交易。
- 投入投资账户属于资金流，不是新的收入；取出同理不算工资收入。
- 本周期投资完成额按实际投入金额计算，不受历史账户市值和市场涨跌影响。
- MVP 不做证券级持仓、自动行情、手续费/拆分/分红再投资等专业证券记账能力。

## 数据模型 V3

新增：

- `investmentAccounts`：投资账户、期初净投入（可未知）、当前市值、更新时间。
- `investmentFlows`：投入/取出资金流，可归属工资周期。
- `marketValueSnapshots`：手动市值快照。

v1 / v2 备份升级到 v3 时三个集合默认为空，历史账目和周期数据不变。

## 计算口径

- `净投入 = 期初净投入 + 累计投入 - 累计取出`。
- `浮动盈亏 = 当前市值 - 净投入`；期初净投入未知时不显示收益。
- `本周期投资实际 = nature=投资 的支出 + 本周期 contribution 资金流`。
- withdrawal 不作为收入，也不倒扣已经完成的本周期投资目标。
- 市值快照不进入收入、支出和 70/5/25 资金流口径。
